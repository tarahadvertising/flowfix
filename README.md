# FLOWFIX — Premium Industrial Engineering Website

A modern, conversion-focused corporate website for **FLOWFIX**, featuring advanced industrial engineering solutions with a sophisticated design system. Built with React 18, Vite, Tailwind CSS, Framer Motion, React Icons and Swiper.

## 🚀 Key Features

- **Modern Hero Section**: Engaging headline with industrial background imagery
- **Enhanced Content Flow**: Optimized section hierarchy for better user journey
- **New Highlights Section**: Key differentiators and competitive advantages
- **Premium Design**: Metallic gold/silver theme with flat, clean aesthetics
- **Responsive Layout**: Mobile-first design with seamless cross-device experience
- **Smooth Animations**: Framer Motion powered micro-interactions and scroll reveals
- **Component Architecture**: Modular, reusable React components

## 🛠 Tech Stack

- React 18 + Vite
- Tailwind CSS (custom metallic gold/silver theme)
- Framer Motion (scroll reveals, stagger, hover micro-interactions)
- React Icons
- Swiper JS (testimonials carousel)

## 📁 Enhanced Project Structure

```
src/
 ├─ components/   Reusable UI building blocks
 ├─ sections/     Page sections (Hero, Highlights, Services, …)
 ├─ pages/        Top-level pages
 ├─ layouts/      Header, Footer, MainLayout
 ├─ assets/       SVGs / images
 ├─ data/         Static content (services, projects, testimonials, …)
 ├─ hooks/        Custom React hooks
 ├─ utils/        Helpers
 ├─ styles/       Global CSS
 └─ App.jsx
```
